# Lector de Facturas & Cotejo Inteligente con Gemini IA

Aplicacion para lectura, extraccion y cotejo automatico de comprobantes de compra (facturas en PDF e imagenes) con el catalogo maestro de Tango Gestion, asistida por la API de Gemini 3.5 Flash Lite.

## Caracteristicas
- Lectura Inteligente con Gemini 3.5 Flash Lite (PDF e imagenes).
- Catalogo Maestro de 1.370 articulos Z en vivo sincronizado con Supabase.
- Sincronizacion inteligente con exportaciones crudas de Tango ("Actualizar con nueva tabla").
- Descarga directa en un clic de "Catalogo de Articulos.xlsx" con 100% de sinonimos.
- Bitacora de Articulos No Encontrados para gestionar altas en Tango.
- Modal Flotante y Picture-in-Picture ("Mostrar") para carga rapida en Tango.
